# 🤖 Jarvis AI Assistant

A personal AI desktop assistant built with Python, designed to provide voice interaction, AI conversations, Windows automation, file management, memory, and other useful desktop features.

## ✨ Features

* 💬 AI-powered conversations
* 🎤 Voice input
* 🔊 Text-to-speech voice output
* 👂 Wake-word detection
* 🖥️ Modern desktop GUI
* 📂 File management
* 🚀 Application control
* 🧠 Long-term memory
* 📝 Task management
* 🌐 Web search
* 📸 Screenshot capture
* 💻 Python code generation
* 🔐 Permission management
* 🛠️ System command support
* 🔔 System tray support

## 🧰 Technologies Used

* Python
* Ollama
* Llama 3.2
* CustomTkinter
* Edge-TTS
* SoundDevice
* Speech Recognition
* VLC
* Windows system tools

## ⚙️ How It Works

Jarvis combines a local language model with Python-based desktop functionality.

User
  ↓
Voice / Text Input
  ↓
Command Processor
  ↓
AI Brain
  ↓
Ollama + Llama 3.2
  ↓
Jarvis Response / Action
  ↓
Voice / GUI Output
